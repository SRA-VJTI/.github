# Society of Robotics and Automation (SRA), VJTI

The robotics club of VJTI, Mumbai. We work in Robotics, Machine Vision, Embedded Systems, and Automation.

[sravjti.in](https://sravjti.in)

## Flagship Workshops

We conduct **hands-on workshops** for First Year students every year:

- **[Wall-E](https://github.com/SRA-VJTI/Wall-E)**  
  Line-following + Self Balancing robot based on PID Controls, powered by ESP32.

- **[Pixels](https://github.com/SRA-VJTI/Pixels)**  
  Introduction to Computer Vision and implementing key OpenCV algorithms from scratch in C++.

- **[MARIO](https://github.com/SRA-VJTI/MARIO)**  
  ROS-based robotic manipulator with forward & inverse kinematics, powered by ESP32.
  
## Study Groups

We run focused **study groups** every year covering core topics.

- **[Robotics Study Group](https://sravjti.in/robotics-study-group/)**  
  From robot learning fundamentals to modern robot foundation models (adapted from ETH Zurich’s course).

- **[Embedded Systems Study Group](https://sravjti.in/embedded-systems-study-group/)**  
  Covering electronics, ESP32, FreeRTOS, memory, peripherals, and more.

- **[Computer Vision Study Group](https://sravjti.in/computer-vision-study-group/)**  
  Computer vision fundamentals, starting with human vision, grid detection, etc.

- **[Linear Algebra Study Group](https://sravjti.in/linear-algebra-study-group/)**  
  In-depth study covering vector spaces, matrices, eigenvalues, orthogonality.
